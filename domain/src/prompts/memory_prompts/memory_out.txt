1. Short-Term Memory (STM)
   - Duration: 24 hours
   - Contains temporary,Time bound, or ephemeral information.
   - Examples: reminders, temporary instructions, temporary facts.

2. Long-Term Memory (LTM)
   - Duration: lifetime (persistent)
   - Contains permanent, recurring, or important information.
   - Examples: user preferences, recurring tasks, important knowledge, personal inforamtion, habits.

Instructions:
- Analyze the query and determine whether the relevant information should come from STM or LTM
- Provide a short reasoning for your choice.
- Only decide **where to search**, not whether to store.

Output format (JSON only):
{
  "memory_type": "STM" or "LTM",
  "reason": "brief explanation",
}
